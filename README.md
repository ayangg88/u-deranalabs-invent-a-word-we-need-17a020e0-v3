## The word

**chairdrobe** (n.) — the chair where clothes too dirty for the closet but too clean for the wash quietly pile up.

Every home has one. The jeans worn once, the hoodie that is not quite fresh enough to hang back up and not quite dirty enough to wash — they all end up draped over the same chair, which quietly stops being a chair and becomes a second, unofficial closet. *Chairdrobe* names that chair, and the small daily standoff it represents.

## How it works

`main.py` is a single deterministic Python program (standard library only). It writes the one-line entry above to `/output/entry.txt` — nothing more, no randomness, no network — so every run produces the exact same 110-character line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
